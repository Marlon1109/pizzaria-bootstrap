# Pizzaria do JS com Bootstrap

Projeto acadêmico de Desenvolvimento Front-End para Web, baseado no tutorial **Pizzaria do JS com Bootstrap**.

## Funcionalidades
- Cardápio responsivo com pizzas e bebidas
- Navegação adaptada a celular, tablet e notebook
- Formulário de pedidos com validação
- Cálculo automático do total e desconto VIP de 10%
- Recibo em modal Bootstrap
- Tabela de horários e modal de contato
- Aviso de sucesso após fechar o recibo

## Tecnologias
HTML5, JavaScript e Bootstrap 5.3.3 via CDN.

## Como executar
Abra `pizzaria.html` com a extensão Live Server no VS Code. É necessária conexão com a internet para carregar o Bootstrap.

## Observações
Projeto demonstrativo: não envia pedidos reais. Os dados de contato são fictícios. Uma bebida opcional é somada por pedido antes do desconto VIP.
